# 📸 Fotos para Instagram — scripts prontos para o Gemini

> Estilo de uso: cole o prompt inteiro no **Gemini** pedindo *imagem*.
> Se ele responder em texto, escreva no começo: `Gere a imagem agora:`.
> Sempre **sem texto na imagem** (modelo erra acento em português) —
> a frase de impacto entra depois, no Canva ou direto no Instagram.
> Proporção: **4:5** para feed · **1:1** para perfil.

---

## 🎯 PROMPT-BASE (troque só o que está entre `[ ]`)

```
Gere uma foto realista, proporção vertical 4:5, para post de Instagram.

CENA: [O QUE ESTÁ ACONTECENDO]
PESSOA: professora brasileira, ~35 anos, [EXPRESSÃO/CARGO]
LUGAR: sala de aula brasileira real, [DETALHE DO LUGAR]
LUZ: [TIPO DE LUZ]
ESTILO: fotografia documental, realista, cores [QUENTES/SUAVES], nada de
cara de banco de imagens corporativo
SEM TEXTO na imagem, sem logos, sem marca d'água
Espaço limpo na parte de baixo para eu escrever depois.
```

## 🧷 Como usar (3 passos)

1. Cole o prompt inteiro. Se vier texto em vez de imagem, escreva antes:
   `Gere a imagem agora:`
2. Depois da 1ª foto, peça: `Gere 3 variações desta mesma foto, mudando só o
   ângulo e a luz.` → dá um carrossel coerente sem trocar de post.
3. Texto entra depois (Canva/Instagram), **nunca** pedido ao Gemini.
